Instagram Setup Checklist

  1. Create a Meta Appdevelopers.facebook.com → My Apps → Create App → Select "Other" / "Business"
  2. Add Instagram Login ProductAdd "Instagram API with Instagram Login" (Direct Instagram login, no Facebook Page required!)
  3. Paste the Redirect URIInstagram API with Instagram Login → Settings → Valid OAuth Redirect URIs → Paste the URL shown on the left
  4. Configure WebhookInstagram → Webhooks → Paste Webhook Callback URL & Verify Token → Subscribe to comments & messages
  5. Permissions & ScopesInstagram Login uses: instagram_business_basic, instagram_business_manage_messages, instagram_business_manage_comments
  6. Enter App ID & App SecretCopy from App Settings > Basic → Paste here and click Save credentials
In Development mode, add your own Instagram account under Instagram API with Instagram Login → Roles / User Token Generator to test immediately.
