Meta Setup Verification Checklist

Essential settings required by Meta Graph API for automated DMs:

  • 1. Webhook Fields: In Meta App → Webhooks → Instagram, ensure comments and messages are subscribed.
  • 2. Tester Invitation Accepted: In the Instagram mobile app for your tester account: Settings → Website permissions → Tester invitations → Tap Accept.
  • 3. Connected Tools Toggle: On your professional IG account (@satnamwebservices): Settings → Messages and story replies → Message controls → Connected Tools → Allow access to messages = ON.
  • 4. Separate Account Testing: Test comments using your personal tester account, not from @satnamwebservices (Instagram prohibits self-DMs).
